# Модуль “Agent” — Техническое задание (Версия 1.1 — Фундамент + GitHub Copilot SDK)

Документ описывает архитектуру и требования к созданию модуля интеллектуального администратора портала.  
Модуль должен быть реализован **как агент на основе GitHub Copilot SDK**, с архитектурой Skills, совместимой с SDK‑подходом.

Цель — создать масштабируемый, модульный, расширяемый каркас, разделённый на frontend и backend, где backend — это ядро SDK‑агента.

---

# ⚙️ 0. Требования по GitHub Copilot SDK

Модуль должен быть построен с учётом следующих принципов:

- Backend реализуется как **агент**, совместимый с GitHub Copilot SDK.
- Skills должны быть оформлены как отдельные модули, которые могут быть зарегистрированы в SDK‑агенте.
- Agent Engine должен быть структурирован так, чтобы в будущем его можно было подключить к SDK‑контексту.
- API‑слой должен быть готов к интеграции с SDK‑вызовами.
- Архитектура должна позволять расширять агента новыми Skills без изменения существующего кода.

# 🧠 2. Backend — архитектура и функционал (SDK‑совместимая)

Backend состоит из трёх уровней:  
**Agent Engine**, **Skill Registry**, **Message Router**.

Backend должен быть готов к подключению GitHub Copilot SDK.

---

## 2.1. Agent Engine (`agentEngine.ts`)

Функции:
- принимать команды от frontend  
- определять, какой Skill должен быть вызван  
- вызывать Skill  
- возвращать результат  
- управлять состоянием  
- быть совместимым с моделью SDK‑агента  

Структура должна быть модульной, чтобы позже можно было подключить:

```ts
import { CopilotKit } from "@copilot/sdk";
```

---

## 2.2. Skill Registry (`skillRegistry.ts`)

Функции:
- регистрация Skills  
- маршрутизация  
- доступ к контексту  
- структура должна быть совместима с SDK‑подходом:

```ts
export interface AgentSkill {
  name: string;
  execute: (payload: any) => Promise<any>;
}
```

---

## 2.3. Message Router (`messageRouter.ts`)

Функции:
- принимать сообщения от frontend  
- передавать их в Agent Engine  
- возвращать ответы  
- структура должна быть готова к SDK‑вызовам  

---

# 🧩 3. Backend — Skills (первоначальный набор)

Создать 4 Skills с базовой структурой, совместимой с SDK‑агентом.

---

## 3.1. Form Generator Skill (`formGeneratorSkill.ts`)

Функции:
- генерировать JSON‑описание формы  
- возвращать структуру:

```ts
{
  title: string;
  fields: Array<{
    id: string;
    type: string;
    label: string;
    placeholder?: string;
  }>
}
```

---

## 3.2. File Writer Skill (`fileWriterSkill.ts`)

Функции:
- принимать данные формы  
- создавать файлы в репозитории  
- поддерживать форматы: `.json`, `.md`, `.tsx`  
- предусмотреть заглушку для сохранения изображений  
- структура должна быть совместима с SDK‑агентом  

---

## 3.3. Books Skill (`booksSkill.ts`)

Функции:
- создавать структуру данных для карточек книг  
- генерировать текстовые блоки (заглушка)  
- структура должна быть совместима с SDK‑агентом  

---

## 3.4. Attractions Skill (`attractionsSkill.ts`)

Функции:
- создавать структуру данных для достопримечательностей  
- инициировать генерацию изображений (заглушка)  
- формировать галерею  
- структура должна быть совместима с SDK‑агентом

# 💡 Подсказки для Copilot VS Code

Copilot, выполняя это ТЗ:
- создавай код поэтапно  
- сначала создай структуру папок  
- затем backend (core → api → skills)  
- затем frontend  
- используй чистые, модульные компоненты  
- добавляй комментарии к ключевым функциям  
- не реализуй сложную логику — только каркас  
- оставляй заглушки для будущего функционала  
- соблюдай совместимость с GitHub Copilot SDK
