# Agent v1.9 — Техническое задание (Skill normalizeCity)

Цель версии v1.9 — добавить Skill `normalizeCity`, который нормализует структуру данных города, создавая недостающие поля и файлы.  
После выполнения нормализации каждый город должен иметь:

- `meta`  
- `description`  
- `cover`  
- `hero`  
- `gallery` (папка, пустая по умолчанию)  
- `data.json` с полной структурой  

---

# 1. Новый Skill: normalizeCity

Файл:
```
/components/agent/skills/normalizeCity.ts
```

Функции Skill:
- принимает название города (`cityName`)
- создаёт недостающие папки
- создаёт или дополняет `data.json`
- добавляет недостающие поля
- возвращает стандартизированный ответ

---

# 2. Команды, которые должен распознавать Агент

Агент должен понимать команды вида:

- «Нормализуй город Augsburg»
- «Приведи структуру города Munich в порядок»
- «Создай недостающие данные для города Berlin»
- «Обнови структуру города Hamburg»

---

# 3. Логика обработки команд в AgentCore

## 3.1. Определение команды normalizeCity

Команда считается `normalizeCity`, если содержит:

- «нормализуй город»
- «нормализуй»
- «структуру города»
- «приведи город»
- «обнови структуру города»

## 3.2. Извлечение параметров

Из текста команды нужно извлечь:

- `cityName`

Пример:
«Нормализуй город Augsburg»

Результат:
- `cityName = "Augsburg"`

---

# 4. Поведение Skill normalizeCity

## 4.1. Входные данные

```ts
normalizeCity(cityName: string)
```

## 4.2. Действия Skill

1. Создать slug города:
   ```
   citySlug = slugify(cityName)
   ```

2. Проверить, существует ли город:
   ```
   /data/landmarks/{citySlug}/index.json
   ```

3. Создать структуру папок, если их нет:
   ```
   /data/landmarks/{citySlug}/cover/
   /data/landmarks/{citySlug}/hero/
   /data/landmarks/{citySlug}/gallery/
   ```

4. Создать или обновить `data.json`:
   ```
   /data/landmarks/{citySlug}/data.json
   ```

5. Добавить недостающие поля:

```json
{
  "meta": {
    "title": "",
    "subtitle": "",
    "keywords": [],
    "shortDescription": ""
  },
  "description": "",
  "cover": "",
  "hero": "",
  "gallery": []
}
```

6. Не изменять существующие данные, только добавлять недостающие.

7. Сохранить файл.

8. Вернуть результат:

```json
{
  "type": "success",
  "message": "Город нормализован",
  "data": {
    "city": "{cityName}",
    "normalized": true
  }
}
```

---

# 5. Интеграция с AgentCore

AgentCore должен:

1. Распознать команду как `normalizeCity`
2. Извлечь параметры
3. Вызвать Skill:
   ```ts
   const result = await normalizeCity(cityName);
   ```
4. Вернуть стандартизированный ответ.

---

# 6. Ограничения версии v1.9

Skill НЕ должен:

- изменять slug  
- изменять названия городов  
- удалять существующие данные  
- создавать достопримечательности  

Только нормализация структуры города.
