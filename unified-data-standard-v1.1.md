# Unified Data Standard v1.1

Документ описывает единый стандарт данных для источников (TEASER/FULL) и итоговый формат `data.json`.

## 1. Шаблон ввода данных (v1.1)

Шаблон предназначен для ручного ввода или подготовки исходных данных перед обработкой Агентом.

**Обязательные поля:**

- `title` — заголовок сущности.
- `shortDescription` — краткое описание (1–2 предложения).

**Опциональные поля:**

- `subtitle` — подзаголовок.
- `description` — расширенное описание (абзацы/сводка).
- `hero` — путь к главному изображению.
- `cover` — запасное изображение, если `hero` отсутствует.
- `gallery` — список путей изображений.
- `facts` — список фактов (строки).
- `tags` — ключевые метки.
- `year` — год/период.

Рекомендуемый шаблон ввода:

```json
{
  "title": "...",
  "subtitle": "...",
  "shortDescription": "...",
  "description": "...",
  "hero": "...",
  "cover": "...",
  "gallery": ["..."],
  "facts": ["..."],
  "tags": ["..."],
  "year": 2025
}
```

## 2. Итоговая структура `data.json`

Итоговый файл хранит нормализованные данные после обработки Агентом. Структура фиксирована:

```json
{
  "meta": {
    "title": "...",
    "subtitle": "...",
    "shortDescription": "...",
    "keywords": ["..."],
    "year": 2025
  },
  "description": "...",
  "hero": "...",
  "gallery": ["..."],
  "facts": ["..."]
}
```

Пояснения:

- `meta` — метаданные, пригодные для карточек и навигации.
- `description` — основное описание (для страниц/разделов).
- `hero` — главный визуальный якорь.
- `gallery` — галерея изображений (опционально).
- `facts` — список коротких фактов (опционально).

## 3. Правила использования

### 3.1 Страница достопримечательности (TEASER)

Назначение: компактное превью в меню и карточках.

Использование:

- `meta.title`
- `meta.shortDescription`
- `hero` (если отсутствует, использовать `cover` или первый элемент `gallery`)

Ограничения:

- Без длинных текстов.
- Без тяжёлых массивов.

### 3.2 Глава книги (FULL)

Назначение: полный контент для основного экрана.

Использование:

- `meta` полностью
- `description`
- `hero`
- `gallery`
- `facts`

Ограничения:

- Содержимое должно быть связным и пригодным для длинного чтения.

### 3.3 Админ‑панель

Назначение: редактирование и валидация исходных данных.

Использование:

- Ввод по шаблону v1.1.
- Автоподстановка `hero`/`cover` и базовая валидация.
- Сборка итогового `data.json` выполняется Агентом.

## 4. Важное правило

TEASER и FULL **не хранятся** в JSON. Они **генерируются Агентом** на основе шаблона ввода и итоговой структуры `data.json`.
