# Модуль “Landmarks” — Техническое задание (Версия 1.2)

Цель версии 1.2 — исправить механику меню, поведение зон и привести модуль к архитектурно корректному состоянию, полностью соответствующему модели landmarks v2.0.

---

# 🧭 1. Общая архитектура модуля

Модуль landmarks всегда состоит из двух или трёх зон:

## 1) Левая зона — постоянное меню
- отображается всегда
- содержит список городов
- выбранный город раскрывается
- выбранная достопримечательность подсвечивается

## 2) Центральная зона — рабочая зона
- на главной странице: информационный блок
- при выборе города: информация о городе (или пустая зона)
- при выборе достопримечательности: текстовая часть

## 3) Правая зона — галерея (только при выборе достопримечательности)
- вертикальная колонка миниатюр
- модальное окно
- зум + панорамирование (pan)

---

# 🧱 2. Логика меню (аккордеон)

Меню работает как аккордеон и управляет состоянием модуля.

## 2.1. При загрузке модуля
- показывается заголовок «Города»
- показывается список городов
- никакие города не раскрыты
- правая зона отсутствует
- центральная зона — информационный блок модуля

## 2.2. При выборе города
- выбранный город раскрывается
- показывается список достопримечательностей
- все другие города закрываются
- центральная зона показывает информацию о городе (или остаётся пустой)
- правая зона отсутствует

## 2.3. При выборе достопримечательности
- выбранный город остаётся раскрытым
- выбранная достопримечательность подсвечена
- центральная зона показывает текстовую часть
- правая зона показывает галерею

## 2.4. При выборе другого города
- предыдущий город закрывается
- новый город раскрывается
- центральная зона показывает информацию о новом городе
- правая зона исчезает
