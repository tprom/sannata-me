# Agent v1.0 — Техническое задание (Минимальный рабочий Агент)

Цель версии v1.0 — создать базовую архитектуру Агента, который принимает текстовые команды, определяет нужный Skill, выполняет действие и возвращает результат в интерфейс. Агент должен уметь работать с модулем landmarks.

---

# 1. Архитектура Агента

Агент состоит из трёх уровней:

## 1.1. Agent Core (ядро)
Функции:
- принимает текст команды
- анализирует команду
- определяет, какой Skill должен быть вызван
- вызывает Skill
- возвращает результат в UI

Файл:
```
/components/modules/agent/core/AgentCore.ts
```

---

## 1.2. Skills (способности)
Каждый Skill — отдельный модуль.

Для версии v1.0 создаётся один Skill:

### Skill: createLandmark
Функции:
- принимает название города
- принимает название достопримечательности
- создаёт slug
- создаёт структуру папок
- создаёт data.json
- создаёт пустую галерею
- обновляет index.json города
- возвращает результат

Файл:
```
/components/modules/agent/skills/createLandmark.ts
```

---

## 1.3. Agent UI
Интерфейс уже существует. Нужно:
- подключить AgentCore
- передавать текст команды в ядро
- отображать результат выполнения Skill
- отображать ошибки

Файл:
```
/components/modules/agent/AgentModule.tsx
```

---

# 2. Формат команд

Агент принимает команды в виде обычного текста.

Примеры:
- «Создай достопримечательность Perlachturm в городе Augsburg»
- «Добавь новую достопримечательность Dom в Augsburg»
- «Создай карточку Rathaus в городе Augsburg»

---

# 4. Skill: createLandmark

## Входные данные:
- city (string)
- name (string)

## Действия:
1. Проверить, существует ли город  
2. Создать slug  
3. Создать папку:
```
/data/landmarks/{city}/{slug}/
```
4. Создать папку:
```
gallery/
```
5. Создать файл:
```
data.json
```
6. Добавить запись в:
```
/data/landmarks/{city}/index.json
```
7. Вернуть объект:
```
{
  success: true,
  message: "Достопримечательность создана",
  slug: "...",
  city: "..."
}
```

---

# 5. Формат ответа Агента

Агент должен возвращать объект:

```
{
  type: "success" | "error",
  message: string,
  data?: any
}
```

UI должен отображать:
- зелёный блок — успех
- красный блок — ошибка

---

# 6. Ограничения версии v1.0

Агент НЕ должен:
- генерировать текст
- генерировать изображения
- создавать галерею автоматически
- анализировать структуру данных
- предлагать действия

Только механика Skills.
