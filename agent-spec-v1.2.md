# Agent v1.2 — Техническое задание (Skill updateLandmark)

Цель версии v1.2 — добавить Skill `updateLandmark`, который позволяет Агенту обновлять данные существующей достопримечательности в модуле landmarks.

---

# 1. Новый Skill: updateLandmark

Файл:
```
/components/agent/skills/updateLandmark.ts
```

Функции Skill:
- принимает название города (`cityName`)
- принимает название достопримечательности (`landmarkName`)
- принимает объект обновлений (`updates`)
- находит нужную достопримечательность
- обновляет её данные в `data.json`
- при необходимости обновляет запись в `index.json`
- возвращает стандартизированный ответ

---

# 2. Команды, которые должен распознавать Агент

Агент должен понимать команды вида:

- «Обнови описание Perlachturm в Augsburg: добавь текст …»
- «Измени название достопримечательности Dom в городе Augsburg на Cathedral»
- «Обнови данные Rathaus в Augsburg»
- «Добавь в описание Perlachturm фразу …»
- «Исправь текст достопримечательности Dom в Augsburg»

---

# 3. Логика обработки команд в AgentCore

## 3.1. Определение команды обновления достопримечательности

AgentCore должен определять команду как `updateLandmark`, если текст содержит:

- «обнови»
- «измени»
- «исправь»
- «добавь в описание»

и при этом содержит название города и достопримечательности.

Пример:

```ts
if (
  command.includes("обнови") ||
  command.includes("измени") ||
  command.includes("исправь") ||
  command.includes("добавь в описание")
) {
  return "updateLandmark";
}
```

## 3.2. Извлечение параметров

Из текста команды нужно извлечь:

- `cityName`
- `landmarkName`
- `updates` — объект, содержащий изменения (например, новое описание)

Пример:
- команда: «Обнови описание Dom в Augsburg: добавь текст Новый текст»
- результат:
  - `cityName = "Augsburg"`
  - `landmarkName = "Dom"`
  - `updates = { description: "Новый текст" }`

---

# 4. Поведение Skill updateLandmark

## 4.1. Входные данные

```ts
updateLandmark(cityName: string, landmarkName: string, updates: object)
```

## 4.2. Действия Skill

1. **Создать slug города**
   ```
   citySlug = slugify(cityName)
   ```

2. **Проверить, существует ли город**
   - проверить наличие:
     ```
     /data/landmarks/{citySlug}/index.json
     ```

3. **Найти достопримечательность в index.json**
   - загрузить список
   - найти запись по названию или slug
   - если нет → вернуть ошибку:
     ```json
     {
       "type": "error",
       "message": "Достопримечательность не найдена"
     }
     ```

4. **Загрузить файл data.json достопримечательности**
   ```
   /data/landmarks/{citySlug}/{landmarkSlug}/data.json
   ```

5. **Обновить данные**
   - объединить старые данные с `updates`
   - пример:
     ```ts
     const newData = { ...oldData, ...updates }
     ```

6. **Сохранить обновлённый data.json**

7. **(Опционально) Обновить запись в index.json**
   - если изменилось название достопримечательности

8. **Вернуть результат**
   ```json
   {
     "type": "success",
     "message": "Данные достопримечательности обновлены",
     "data": {
       "city": cityName,
       "landmark": landmarkName,
       "updates": updates
     }
   }
   ```

---

# 5. Интеграция с AgentCore

AgentCore должен:

1. Распознать команду как `updateLandmark`
2. Извлечь параметры
3. Вызвать Skill:
   ```ts
   const result = await updateLandmark(cityName, landmarkName, updates);
   ```
4. Вернуть результат в UI в стандартизированном формате.

---

# 6. Ограничения версии v1.2

Skill updateLandmark НЕ должен:

- генерировать текст
- генерировать изображения
- создавать новые достопримечательности
- создавать новые города
- изменять структуру данных

Только обновление существующих данных.
