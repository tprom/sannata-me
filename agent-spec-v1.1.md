# Agent v1.1 — Техническое задание (Skill createCity)

Цель версии v1.1 — добавить новый Skill `createCity`, который позволяет Агенту создавать новый город в модуле landmarks с корректным формированием структуры данных.

---

# 1. Новый Skill: createCity

Файл:
```
/components/agent/skills/createCity.ts
```

Функции Skill:
- принимает название города (`cityName`)
- создаёт slug города
- создаёт структуру папок
- создаёт файл `index.json` для достопримечательностей города
- (опционально) создаёт файл `data.json` для города, если используется
- возвращает стандартизированный ответ

---

# 2. Команды, которые должен распознавать Агент

Агент должен понимать команды вида:

- «Создай город Berlin»
- «Добавь новый город Munich»
- «Создай новый город Hamburg»
- «Добавь город Dresden в модуль достопримечательностей»

---

# 3. Логика обработки команд в AgentCore

## 3.1. Определение команды создания города

AgentCore должен определять команду как `createCity`, если текст содержит:

- «создай город»
- «добавь город»
- «новый город»

Пример:

```ts
if (
  command.includes("создай город") ||
  command.includes("добавь город") ||
  command.includes("новый город")
) {
  return "createCity";
}
```

## 3.2. Извлечение параметров

Из текста команды нужно извлечь:

- `cityName` — строка, название города

Пример:
- команда: «Создай город Berlin»
- результат: `cityName = "Berlin"`

---

# 4. Поведение Skill createCity

## 4.1. Входные данные

```ts
createCity(cityName: string)
```

## 4.2. Действия Skill

1. **Создать slug города**  
   - нижний регистр  
   - латиница  
   - без пробелов  
   Пример: `"New York" → "new-york"`

2. **Проверить, существует ли город**
   - проверить наличие папки:
     ```
     /data/landmarks/{citySlug}/
     ```
   - если существует → вернуть ошибку:
     ```json
     {
       "type": "error",
       "message": "Город уже существует",
       "data": { "city": cityName, "slug": citySlug }
     }
     ```

3. **Создать папку города**
   ```
   /data/landmarks/{citySlug}/
   ```

4. **Создать файл index.json**
   ```
   /data/landmarks/{citySlug}/index.json
   ```
   Содержимое:
   ```json
   {
     "city": "{cityName}",
     "slug": "{citySlug}",
     "landmarks": []
   }
   ```

5. **(Опционально) Создать data.json для города**  
   Только если используется в текущей архитектуре.

   ```
   /data/landmarks/{citySlug}/data.json
   ```

   Содержимое:
   ```json
   {
     "title": "{cityName}",
     "description": "",
     "meta": {}
   }
   ```

6. **Вернуть результат**
   ```json
   {
     "type": "success",
     "message": "Город успешно создан",
     "data": {
       "city": "{cityName}",
       "slug": "{citySlug}"
     }
   }
   ```

---

# 5. Интеграция с AgentCore

AgentCore должен:

1. Распознать команду как `createCity`
2. Извлечь `cityName`
3. Вызвать Skill:
   ```ts
   const result = await createCity(cityName);
   ```
4. Вернуть результат в UI в формате:
   ```json
   {
     "type": "success" | "error",
     "message": "...",
     "data": { ... }
   }
   ```

---

# 6. Ограничения версии v1.1

Skill createCity НЕ должен:

- генерировать текст описания города
- создавать достопримечательности
- изменять существующие города
- модифицировать другие модули

Только создание структуры нового города.
