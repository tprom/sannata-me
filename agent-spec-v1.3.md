# Agent v1.3 — Техническое задание (Skill normalizeLandmark)

Цель версии v1.3 — добавить Skill `normalizeLandmark`, который приводит структуру данных достопримечательности к единому стандарту, создаёт недостающие поля и гарантирует, что страница достопримечательности не будет падать из‑за отсутствия данных.

---

# 1. Новый Skill: normalizeLandmark

Файл:
```
/components/agent/skills/normalizeLandmark.ts
```

Функции Skill:
- принимает название города (`cityName`)
- принимает название достопримечательности (`landmarkName`)
- находит соответствующую папку и файлы
- проверяет структуру `data.json`
- добавляет недостающие поля
- создаёт пустые структуры, если их нет
- сохраняет обновлённый файл
- возвращает стандартизированный ответ

---

# 2. Команды, которые должен распознавать Агент

Агент должен понимать команды вида:

- «Нормализуй данные Dom в Augsburg»
- «Приведи в порядок достопримечательность Perlachturm в городе Augsburg»
- «Проверь структуру Rathaus в Augsburg»
- «Исправь структуру данных Dom»
- «Добавь недостающие поля в Perlachturm»

---

# 3. Логика обработки команд в AgentCore

## 3.1. Определение команды normalizeLandmark

AgentCore должен определять команду как `normalizeLandmark`, если текст содержит:

- «нормализуй»
- «приведи в порядок»
- «исправь структуру»
- «проверь структуру»
- «добавь недостающие поля»

## 3.2. Извлечение параметров

Из текста команды нужно извлечь:

- `cityName`
- `landmarkName`

Пример:
- команда: «Нормализуй данные Dom в Augsburg»
- результат:
  - `cityName = "Augsburg"`
  - `landmarkName = "Dom"`

---

# 4. Поведение Skill normalizeLandmark

## 4.1. Входные данные

```ts
normalizeLandmark(cityName: string, landmarkName: string)
```

## 4.2. Действия Skill

1. **Создать slug города**
   ```
   citySlug = slugify(cityName)
   ```

2. **Проверить, существует ли город**
   - проверить наличие:
     ```
     /data/landmarks/{citySlug}/index.json
     ```

3. **Найти достопримечательность в index.json**
   - загрузить список
   - найти запись по названию или slug
   - если нет → вернуть ошибку:
     ```json
     {
       "type": "error",
       "message": "Достопримечательность не найдена"
     }
     ```

4. **Загрузить файл data.json**
   ```
   /data/landmarks/{citySlug}/{landmarkSlug}/data.json
   ```

5. **Проверить и создать недостающие поля**

Минимальный стандарт:

```json
{
  "title": "string",
  "description": "string",
  "images": [],
  "meta": {},
  "gallery": []
}
```

Skill должен:

- если нет `meta` → добавить `{}`  
- если нет `gallery` → добавить `[]`  
- если нет `images` → добавить `[]`  
- если нет `description` → добавить пустую строку  
- если нет `title` → взять название из index.json  

6. **Сохранить обновлённый data.json**

7. **Вернуть результат**

```json
{
  "type": "success",
  "message": "Структура данных нормализована",
  "data": {
    "city": "{cityName}",
    "landmark": "{landmarkName}",
    "normalized": true
  }
}
```

---

# 5. Интеграция с AgentCore

AgentCore должен:

1. Распознать команду как `normalizeLandmark`
2. Извлечь параметры
3. Вызвать Skill:
   ```ts
   const result = await normalizeLandmark(cityName, landmarkName);
   ```
4. Вернуть результат в UI в стандартизированном формате.

---

# 6. Ограничения версии v1.3

Skill normalizeLandmark НЕ должен:

- генерировать текст
- генерировать изображения
- создавать новые достопримечательности
- создавать новые города
- изменять slug
- изменять структуру папок
- удалять существующие данные

Только добавление недостающих полей.
