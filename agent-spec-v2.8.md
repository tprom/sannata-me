Copilot, выполни обновление модуля достопримечательностей (v2.8). 
Не изменяй существующую галерею, а только структурируй страницу и добавь недостающие секции.

Задачи:

1. Внедрить Story Card Layout на странице достопримечательности.
   Страница должна состоять из следующих компонентов:
   - HeroSection (hero + затемнение + title + subtitle)
   - TeaserSection (текст TEASER, который будет приходить из данных)
   - GallerySection (использовать существующую галерею)
   - FactsSection (facts.details в виде карточек)
   - MiniLegendSection (первая легенда из facts.legends в виде раскрывающегося блока)
   - BookLinkSection (кнопка "Читать полную историю в книге Кетти")

2. FULL-глава не должна выводиться в публичной части портала.
   Убедись, что компонент не пытается отображать FULL и не содержит логики для его рендера.

3. Добавить fallback-логику:
   - если hero отсутствует → использовать cover
   - если cover отсутствует → использовать первое изображение из gallery
   - если gallery пустая → использовать placeholder
   - если teaser отсутствует → выводить skeleton-заглушку
   - если facts.details пустые → скрывать FactsSection
   - если facts.legends пустые → скрывать MiniLegendSection

4. Обеспечить адаптивность страницы:
   - корректная работа на мобильных, планшетах и десктопах
   - вертикальная структура с плавными отступами

5. Минимальная стилизация:
   - чистая типографика
   - аккуратные отступы
   - лёгкое затемнение hero
   - плавные переходы между секциями

6. Не изменяй структуру данных и не добавляй новые API.
   Только структурируй существующую страницу и добавь недостающие компоненты.
