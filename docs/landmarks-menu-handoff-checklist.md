# Handoff Checklist: Меню модуля достопримечательностей

## Контекст

- Модуль: `landmarks` (Cities → Landmarks)
- Объём: меню (без расширения механики главных страниц)
- Базовый статус: P0 + P1 реализованы

## Для дизайнера (visual sign-off)

- [ ] Иерархия читается: город визуально доминирует над достопримечательностью.
- [ ] Ритм наклонов выглядит живо, но без хаоса.
- [ ] Точка крепления (гвоздь) визуально правдоподобна и не конфликтует с текстом.
- [ ] Длинные названия не ломают композицию (перенос/высота/скролл).
- [ ] Hover-градация соблюдена: город заметнее, вторичный уровень мягче.
- [ ] Mobile-версия не перегружена анимациями и остаётся читаемой.

## Для QA (functional sign-off)

- [ ] При раскрытии/сворачивании нет внешнего layout shift.
- [ ] Повторный клик по активному городу закрывает список.
- [ ] В один момент открыт только один город (`single-open`).
- [ ] Клавиатура: `Tab`, `Enter`, `Space`, `Esc` работают предсказуемо.
- [ ] `focus-visible` заметен на всех интерактивных элементах меню.
- [ ] `prefers-reduced-motion` отключает sway/spring без потери функционала.
- [ ] На touch работает `tap-highlight`, поведение не зависит от hover.

## Артефакты проверки

- [ ] Скриншот desktop (меню + раскрытый город)
- [ ] Скриншот mobile (меню + раскрытый город)
- [ ] Скриншот reduced-motion
- [ ] Краткая заметка QA (pass/fail + найденные дефекты)
- [ ] QA note заполнен по шаблону: `docs/landmarks-menu-qa-note-template.md`
- [ ] При необходимости использовать пример: `docs/landmarks-menu-qa-note-2026-02-25.md`

## Критерий готовности к release-ready

- [ ] Все пункты выше отмечены.
- [ ] Критичных дефектов (P0/P1) нет.
- [ ] Статус в roadmap/трекере обновлён на `release-ready`.
