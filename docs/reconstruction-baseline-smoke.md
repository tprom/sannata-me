# Baseline Smoke Scenarios (Pre-Reconstruction)

Статус: ready
Дата: 2026-03-05

Цель: зафиксировать текущее поведение до архитектурных изменений.

## 1. Routes Smoke

1. Открыть `/{lang}/landmarks` для `ru,en,de,uk`.
2. Открыть `/{lang}/landmarks/{citySlug}` для 3 городов.
3. Открыть `/{lang}/landmarks/{citySlug}/{landmarkSlug}` для 3 объектов.

Ожидание:

- страница рендерится без 500
- левое меню городов отображается
- переходы по ссылкам работают

## 2. Forms Smoke (Agent)

1. В `/{lang}/agent` выбрать:
   - `module-home`
   - `collection-home`
   - `landmark-item`
2. Проверить загрузку формы и отсутствие client error.
3. Сохранить тестовое изменение и проверить ответ API `ok: true`.

Ожидание:

- форма открывается
- сохранение возвращает понятный статус
- создается/обновляется ожидаемый output файл

## 3. Data Consistency Smoke

Для каждого сохранения проверить:

1. Файл записан в ожидаемый путь.
2. Локаль не перетерла соседние языки.
3. Иллюстрации имеют валидные пути.
4. Рендер страницы отражает сохраненное изменение.

## 4. Known Issues Baseline (фиксируем до старта)

1. Возможна рассинхронизация между legacy и envelope путями.
2. Возможна подмена structured формы markdown-панелью на client.
3. Для module-home встречается загрязнение полей секций markdown-заголовками.
4. `landmark` форма пишет во временный backend-файл, не в canonical output.

## 5. Exit Evidence

Для каждого smoke-прогона сохранить:

- маршрут
- timestamp
- статус (pass/fail)
- путь обновленного файла
- краткий комментарий по рискам
